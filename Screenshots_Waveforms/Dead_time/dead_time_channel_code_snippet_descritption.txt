The core dead-time mechanism is implemented within a synchronous always block, as shown in the code snippet for the High-Side output logic. This logic is triggered by registered edge-detection flags to ensure safe, predictable state transitions. When the ideal_hs_falling_edge_r flag is asserted (indicating the ideal High-Side signal has just transitioned from high to low), the module performs two critical actions. First, it immediately forces the final High-Side output (final_hs_out) to a low state, initiating the "break" portion of the "break-before-make" sequence. Second, it prepares the complementary Low-Side switch for activation by loading its delay counter (ls_turn_on_delay_counter) with the software-programmed dead_zone_cycles value. Symmetrical but opposite logic exists for handling a rising edge, which turns off the Low-Side switch and loads the High-Side's delay counter.
The subsequent else if condition manages the turn-on delay itself. This block is active only when a turn-on sequence has been initiated and the corresponding delay counter is non-zero. On each clock cycle, it decrements the counter. Only when the counter reaches its final tick (== 1) is the final_hs_out signal asserted high on the next clock edge. This countdown process creates the essential time gap where both switches are off. This event-driven, counter-based approach guarantees that a complementary switch is never commanded to turn on until after its counterpart has been turned off and the specified dead-time has fully elapsed, robustly preventing any possibility of H-bridge shoot-through.

Explanation of dead_zone_inserter.v
The dead_zone_inserter.v module serves as a high-level, structural wrapper whose sole purpose is to manage the dead-time for the entire three-phase system in a clean and organized manner. It does not contain any complex timing logic itself; instead, it accomplishes its task by instantiating the dead_zone_channel.v "worker" module three separate times—one for each motor phase: U, V, and W.
This parent module provides a simple, unified interface to the rest of the controller. It takes the three "ideal" High-Side signals (ideal_hs_u_in, ideal_hs_v_in, ideal_hs_w_in) and the single, global dead_zone_value_in as inputs. Internally, it passes the clock, reset, and the global dead-zone value down to all three child instances. Crucially, it routes each phase's specific ideal signal to its corresponding dead_zone_channel instance. The final, shoot-through-protected High-Side and Low-Side outputs from each child instance are then wired directly to the top-level output ports of this module. This design elegantly encapsulates the complexity of the three-phase system, presenting a single, easy-to-use "dead-time insertion" block to the main controller.
