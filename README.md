# FPGA-Based-BLDC-Motor-Controller-with-RISC-V-SoC
Complete hardware (Verilog) and software (C) source code for a custom BLDC motor controller, developed as project for the Intelligent Chip course at Tongji University. The files encode a motor controller as an IP peripheral integrated into a System-on-Chip (SoC) built around the Hummingbirdv2 E203 RISC-V processor core (CPU files not included).
